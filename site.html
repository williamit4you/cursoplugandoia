Dúvidas frequentes

Antes de começar.

Preciso saber programar para acompanhar?
Não. A jornada começa com lógica, linguagem C# e orientação a objetos. Quem já conhece o básico pode avançar diretamente para as trilhas seguintes.
O curso é apenas sobre teoria?
Não. A teoria de arquitetura é conectada a exemplos em C#, à construção de uma Web API completa com .NET e aos serviços usados para executar aplicações na AWS.
Arquitetura não é um assunto apenas para desenvolvedores seniores?
Não. Ninguém precisa começar projetando sistemas gigantes, mas compreender responsabilidades, acoplamento, coesão e organização desde cedo evita muitos vícios e acelera a evolução profissional.
O que vou conseguir entender ao final?
Você terá base para explicar as partes de uma aplicação, criar APIs mais organizadas, compreender os princípios SOLID, comparar modelos arquiteturais e reconhecer diferentes formas de integração entre sistemas.
Posso começar pela trilha de arquitetura?
Sim. A formação foi organizada em uma sequência recomendada, mas você pode usar as trilhas conforme seu nível atual e revisar C# ou Web API quando sentir necessidade.
