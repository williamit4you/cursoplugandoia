# Kit de criativos — cursos Plugando IA

Material para anúncios verticais em Meta Ads, Reels e Stories.

## Como usar

- Grave em formato vertical `9:16`.
- Busque vídeos de `20 a 35 segundos`.
- Nos primeiros `2 segundos`, fale o gancho e coloque a mesma frase na tela.
- Use cortes a cada `2 a 4 segundos` entre rosto, página do curso, aplicação e trechos das aulas.
- Termine mostrando o preço e uma única chamada para ação.
- Grave cada roteiro pelo menos duas vezes: uma versão falando para a câmera e outra narrando uma gravação de tela.
- Nos anúncios sobre renda extra ou clientes, fale sempre em **possibilidade**. Não prometa faturamento, emprego ou resultado garantido.

# Sugestão de testes no Meta Ads

Não coloque todas as peças no mesmo conjunto logo no primeiro dia. Uma estrutura inicial simples:

1. **Vibe Coding — ideia:** criativo `01` + Roteiro 1.
2. **Vibe Coding — aprender:** criativo `03` + Roteiro 2.
3. **Vibe Coding — serviços:** criativo `02` ou `04` + Roteiro 3.
4. **Vibe Coding — negócio próprio:** Roteiro 4 com gravação de tela.
5. **Vibe Coding — método:** criativo `05` + Roteiro 5.
6. **Cursos técnicos:** uma peça estática e os dois vídeos de cada curso.
7. **Combo:** uma campanha ampla e outra para remarketing de quem visitou um curso individual.

Para descobrir o que realmente funciona, altere apenas um elemento por teste: gancho, imagem, primeira frase, CTA ou público. Assim fica mais fácil entender por que um anúncio ganhou do outro.
