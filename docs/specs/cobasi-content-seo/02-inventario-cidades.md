## Checklist de ativação por cidade

- [ ] cidade e UF confirmadas;
- [ ] ao menos uma unidade confirmada em fonte oficial;
- [ ] endereço completo e data da verificação;
- [ ] horário e telefone, se publicados, confirmados e datados;
- [ ] recursos locais exclusivos suficientes para não ser doorway;
- [ ] title, meta description, canonical, H1, H2 e H3 revisados;
- [ ] disclosure visível;
- [ ] todos os CTAs usam `/go/loja/cobasi`;
- [ ] nenhum URL externo da Cobasi existe no conteúdo;
- [ ] links internos de entrada e saída presentes;
- [ ] schema corresponde ao conteúdo visível;
- [ ] revisão mobile, acessibilidade e Core Web Vitals;
- [ ] `status = PUBLISHED` e `indexable = true` somente depois das etapas anteriores;
- [ ] URL aparece no sitemap local somente após aprovação.
